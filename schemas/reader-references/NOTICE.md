# NRSVA reader numbering provenance

`nrsva-1.json` adapts the chapter and last-verse counts in
[CrossWire JSword](https://github.com/crosswire/jsword/tree/a2c51f3c3a55416f3c991a67ef3d635c7ee55330/src/main/java/org/crosswire/jsword/versification),
revision `a2c51f3c3a55416f3c991a67ef3d635c7ee55330`. The pinned
`SystemNRSVA` inventory uses the NT order from `SystemDefault` and counts
from `SystemNRSV`. The data are reference metadata, with no translated
wording or editorial headings.

The project assigns Psalm 151 its own `Ps151` book ID and expresses the Letter
of Jeremiah as `EpJer` chapter 1, using the counts for CrossWire's `AddPs` and
Baruch chapter 6 respectively. This matches the separate entries in the
[publisher's Apocrypha list](https://bibleshelp.cambridge.org/hc/en-gb/articles/17710172930578-Which-Apocryphal-Books-are-included-in-my-Bible-version-translation).
The catalogue identifies Greek Esther separately. Its chapter 11 starts at
verse 2, as checked against the [NRSV Anglicized reference display](https://bible.oremus.org/?ql=504581214).
Book names and aliases support existing application inputs. Textual presence, continuity, native correspondence and source
coverage require evidence from each prepared source.
